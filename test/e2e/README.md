# Сквозные тесты (будущее)

Здесь будет тест полного цикла, который доказывает главное обещание Sard — из бэкапа можно восстановиться:

1. Поднять стенд: PostgreSQL сервера, `sard-server`, `sard-agent`, тестовая БД-источник и локальный restic-репозиторий (docker compose).
2. Зарегистрировать агента и запустить сценарий `examples/workflows/postgres-nightly.yaml`.
3. Проверить, что в restic-репозитории появился снапшот, а данные шли агент → хранилище, минуя сервер.
4. Запустить проверку восстановления: копия поднимается во временном контейнере, выполняются проверочные SQL-запросы.
5. Проверить, что `/api/v1/status` вернул непустой `lastVerifiedRestoreAt`, а дашборд показывает «Последнее проверенное восстановление: N минут назад».

Пока бизнес-логики нет, тест не пишется: в каркасе все шаги отвечают «не реализовано».
