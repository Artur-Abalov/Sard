# 2026-10-08 — F8: импорт CA при первом запуске (coder)

Ветка `claude/vibrant-lamport-d49eyk`. Спецификация утверждена владельцем
вместе со всеми предложениями OQ-177…OQ-185 (перенесены в «Закрыто при
сверке», решения — ADR 0052).

## Сделано

- **Сервер.** `CaImportSource` (проверки по таблице причин, в порядке),
  `CaImportContent` (разбор PEM, ключ, самоподписанность, срок),
  `CaImportRefused`/`CaImportRefusal`; `CaDirectory.open` (импорт одним
  переименованием, `OpenedCa` с происхождением, `IMPORT_WRITE_FAILED`);
  `FileCertificateAuthority` пишет отпечаток и происхождение в лог каждого
  старта; `PkiProperties.importDir` (`SARD_PKI_IMPORT_DIR`);
  `GET /api/v1/ca` (`CaInfoController`); строка лога `CERT_UNKNOWN` с тенантом
  и пояснением (`refusalMessage`). `Keys.matches` вынесен из `CaKeyPair` для
  общего использования.
- **Порядок запуска.** Адрес для агентов проверяется до касания каталога CA
  (`ObjectProvider<AgentEndpoint>` в `PkiAutoConfiguration`), иначе старт,
  упавший на адресе, оставил бы импортированный CA (сценарий «Адрес для
  агентов вне имён нового сервера…»). Тест с ранним потребителем CA.
- **Web.** Страница токенов: отпечаток CA (`CopyBox`, одна строка), подсказка,
  ошибка загрузки отдельным сообщением; моки `/api/v1/ca`; строки ru/en.
  `make openapi` выполнен.
- **Документация и стенд.** `deploy/docker-compose.yml`, `docs/operator/03,06,08,09`,
  `docs/operations/pki.md`, `test/e2e/README.md`; e2e `CaImportMoveTest`,
  `CaImportWithoutDatabaseTest`, `SardEnvironment.moveServerImportingCa`.

## Отступления и решения при реализации

- Тесты «файл другого пользователя» (`IMPORT_FILE_UNREADABLE`) и «каталог CA
  только для чтения» не воспроизводятся от root в контейнере разработки:
  читаемость подменяется параметром `isReadable`, остальное — QA
  (`docs/qa/ca-import.md`, шаги 17, 34) и e2e.
- Сертификат источника, который не разбирается, при непустом каталоге CA
  считается «не читается» (WARN), а не отказом: спецификация говорит о
  «каталог убран, файла нет»; случай порчи в ней не описан.
- Предупреждение о сроке пишется до публикации CA; при сбое записи старт всё
  равно падает.
- e2e: база «восстановлена» тем, что остаётся та же; сценарий без базы
  удаляет записи сертификатов агентов.
