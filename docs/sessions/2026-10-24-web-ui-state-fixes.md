# 2026-10-24 — веб: дефекты, найденные съёмкой экранов по состояниям

Консоль снята в ~260 состояниях (Vite + MSW-моки, Playwright, подмена ответов API в браузере); найденные
дефекты — только в `web/`, исправлены напрямую, без конвейера `/ship-feature` (правки отображения, не фичи).

## Сделано
- SFTP-поле отпечатка в шаге самобэкапа показывало ключ локали: ключ `setup.selfBackup.field.fingerprint`
  переименован в `hostKeyFingerprint` (имя поля формы). Тест в `locales.test.ts`: у каждого поля `emptyForm`
  есть подпись в обеих локалях.
- Отзыв токена: любой problem-ответ (500, 503, `onboarding_incomplete`) показывался как «Токен уже истёк».
  Решение вынесено в `revokeRefusal(failure)` (`tokens.ts`, тест): отказ — только `token_used`/`token_expired`,
  остальное — `ErrorBlock`.
- Отказ отзыва при гонке был не виден: `onSettled` перезагружал список, строка теряла кнопку и окно
  закрывалось. Список теперь перезагружается при успехе и при закрытии окна после ошибки.
- Длинные значения: `Mono` переносит при нехватке места (`overflow-wrap: anywhere`), `CopyBox` переносит
  команду (`pre-wrap`) и сжимается во flex (`min-width: 0`) — `/repositories` и id репозитория самобэкапа
  больше не выходят за край.
- Мобильная ширина: переключатели языка и темы на узком экране — в меню навигации, не в шапке;
  `RunsTable` прокручивается внутри своей карточки (`Table.ScrollContainer`).
- en: `banners.noRecoveryKey` без согласования числа — переписан как в ru («…: {{count}}.»).

## Проверка
- `./scripts/gate.sh web` — PASSED; каждое исправление проверено скриншотом на dev-сервере с моками.
