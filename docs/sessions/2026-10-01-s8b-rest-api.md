## Что сделано
- **Заглушки заменены.** `UnimplementedApi.kt` удалён; `AgentsApiImpl`, `EnrollmentTokensApiImpl`,
  `SourcesApiImpl`, `RunsApiImpl` — поверх доменных сервисов; тенант — `TenantResolver`.
  `ApiExceptionHandler` (четыре `@RestControllerAdvice`) отвечает problem+json классами контракта.
- **Токены.** Отзыв по В1 (только активный; истёкший — `token_expired`, использованный — `token_used`
  с агентом, повторный — 200 без изменений); `label`; `agentEndpointConfigured`; страницы со
  статусом; строка токена не попадает в журнал (в том числе префикс в DEBUG-логе тела ответа).
- **Агенты.** Список и карточка по последнему Register, онлайн — по менеджеру стримов; отзыв —
  одна транзакция (сертификаты, агент, шаги `queued/dispatched/running` в `lost` с «agent revoked»,
  запуски `failed`), после фиксации стрим закрывается `AGENT_REVOKED`; `Runs.start` берёт ту же
  блокировку строки агента (гонка отзыва и запуска); пометка дубликата `duplicate_session_at`
  (миграция `V202610011200`) по `duplicateDetected`.
- **Источники.** Проверка конфига по `config_schema` из последнего Register (JSON Schema 2020-12,
  `sard-secret`, все нарушения с путём `config/…`, лимит 64 КиБ, нескомпилируемая схема — `invalid_config`
  у `config`, внешние `$ref` не загружаются); `agent_revoked` (422 при создании и замене, 409 при
  запуске); 409 `unknown_plugin`/`unknown_repository` при запуске; список «новые первыми».
- **Запуски, шаги, логи, снимки.** Список с фильтрами (`queuedFrom` включительно, `queuedTo`
  исключительно), карточка, `agentId` шага (В16), счётчики файлов (`V202610011300`), `backup` у любого
  шага с корректным выводом, снимок и для неуспешного шага (`snapshots.partial`), `truncated` и
  серверная строка без `time` в логах, снимки удалённого источника.
- **Контракт К1–К13.** Внесён в аннотации сервера; `make openapi` пересоздал
  `web/src/api/openapi.json` и `schema.d.ts`; моки веба приведены (ordinal 0, мягкое удаление, отзыв
  агента, метка токена, новые поля); `routeTree.gen.ts` без изменений.
- **e2e.** `EnrollmentTokens.create` берёт токен у `POST /api/v1/enrollment-tokens` (вход паролем
  стенда); в `enrollment_tokens` код стенда не пишет.
- **Зависимость.** `com.networknt:json-schema-validator` 3.0.8 — ADR 0031, `docs/dependencies.md`.

## Отклонения и решения, не вынесенные в спецификацию
- **T0.** Спецификация называет T0 = 2026-10-01T12:00:00Z; тесты берут реальное время, округлённое
  до секунды: сертификаты сервера выпускаются по часам сервера, а TLS-рукопожатие gRPC-сценариев
  судит их по реальным часам. Все утверждения — относительно T0.
- **`@startup`.** Сценарии «Пометка дубликата переживает перезапуск сервера» и «После перезапуска
  сервера агент офлайн» не покрыты отдельным тестом с перезапуском контекста: пометка лежит в
  столбце базы (читается карточкой из базы, `AgentsApiIntegrationTest` проверяет чтение заданного
  значения), онлайн — в памяти менеджера стримов. Перезапуск процесса проверяет ручной QA (шаг 43).
- **Файлы в прогрессе.** `files_processed = 0` без `files_total` — «неизвестно» (null): прото не
  различает «0 файлов» и «не считает файлы».
- **`cryptoProvider`.** Репозиторий без провайдера показан как `restic-aes` (имя встроенного,
  `agent/internal/crypto`), поле контракта не nullable.
- **503 у каждой операции.** По К11 — и у `/session`, `/status`, которые базу не трогают.
- **Перечисления в параметрах.** `?status=ACTIVE` отклоняется: Spring при отказе конвертера
  откатывается к `Enum.valueOf`, поэтому имена констант закрыты редактором binder (`WireEnumEditor`).
- **Журнал при DEBUG.** `logging.level.org.hibernate.orm.core: INFO` в `application.yaml`: на DEBUG
  Hibernate печатает состояние сущностей (config источника, output шага); `toString` у `SourceInput`,
  `Source`, `CreatedEnrollmentToken` не содержит значений. `not_implemented` остаётся значением
  `ErrorCode` (история контракта), операций с ним нет.
- **Существующие тесты, которые пришлось изменить** (ожидали заглушки или старые правила):
  `AdminLoginIntegrationTest` (два теста про 501 — теперь 200), `ApiContractIntegrationTest` (501 →
  «нет 501», экспорт = файл консоли), `EnrollmentTokenServiceIntegrationTest` (В1),
  `SourcesIntegrationTest` и `RunsIntegrationTest` (`AgentRevoked`, порядок списка),
  `SardServerIntegrationTest` (список миграций), `ApiSerializationIntegrationTest` (новые поля).
- **Форматирование.** Gate ставит detekt (строка ≤ 120) и ktlint (140) одновременно: ktlint
  сворачивает в одну строку всё, что вмещается в 140, поэтому код пишется так, чтобы ни одна
  конструкция не попадала в окно 121–140 (`.editorconfig` не менялся).

## Ревизия архитектора (B1, B2)
- **B1.** `Agents` и его виды перенесены в домен `dev.sard.server.fleet`; порт `AgentPresence`
  (online, onlineIds, disconnectRevoked) реализует `AgentConnections`; `api` больше не ссылается на
  `agents`. `ArchitectureTest`: новый тест «the api package references nothing from the gRPC or agents
  boundary» — до переноса красный (AgentsApiImpl импортировал `dev.sard.server.agents.*`); `fleet`
  добавлен в `ISOLATED_PACKAGES`. Заодно провайдер по умолчанию `restic-aes` решает домен, не API.
- **B2.** Два детерминированных теста в `AgentStepsApiIntegrationTest` (блокирующее соединение +
  `pg_stat_activity`). Без `PESSIMISTIC_READ` в `Runs.start` падает «a run being started waits…»
  («nobody waited for the agent's row lock»); без `PESSIMISTIC_WRITE` в `Agents.revoke` падает «a
  revocation waits…» (ждёт именно `select`, а не поздний `update`).
- В ADR 0031 и `dependencies.md` записаны расхождение версии Jackson и принятый риск regex DoS.
