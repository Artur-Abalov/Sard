# 1. Требования

## Машина сервера

| Что | Требование |
|---|---|
| ОС | Linux amd64 или arm64 (образ собирается под обе; например OCI Ampere A1 — arm64) |
| Docker | Docker Engine с плагином Compose v2 (`docker compose`); проверено на Docker 29.6.2 |
| Утилиты | `curl`, `openssl` (для quickstart и проверок) |
| CPU | 1 vCPU достаточно для демо и десятков агентов (не нагружалось) |
| Память | 2 ГБ и больше; замер без нагрузки: сервер 491 МиБ, PostgreSQL 60 МиБ (Docker 29.6.2, amd64, JVM по умолчанию) |
| Диск | ~1,2 ГБ под образы (сервер 766 МБ, PostgreSQL 433 МБ в распакованном виде) плюс база: сразу после установки 50 МБ, растёт с журналами шагов и историей запусков |
| Время | синхронизация (chrony, systemd-timesyncd) на сервере и на хостах агентов: расхождение больше 30 с сервер пишет в лог (`clock skew … exceeds 30s`), а сертификаты с неверным временем не проходят проверку |

Сервер не хранит бэкапы: данные идут с хостов агентов прямо в хранилище
(restic). Поэтому диск сервера не зависит от объёма бэкапов.

## Сеть

| Порт | Кто подключается | Протокол | По умолчанию |
|---|---|---|---|
| 9090/tcp | агенты | gRPC, взаимный TLS | открыт: `0.0.0.0:9090` |
| 8080/tcp | браузер (консоль), REST, хосты агентов за пакетами | HTTP без TLS | только `127.0.0.1:8080` |

Агенты сами открывают соединение к серверу — входящие порты на хостах агентов
не нужны, NAT и серый адрес дома не мешают. Если впереди облачный фаервол
(Security List в OCI, Security Group в AWS) **и** фаервол на самом хосте
(в образах Ubuntu и Oracle Linux на OCI iptables по умолчанию режет всё,
кроме 22), порт 9090 открывают в обоих.

Порт 8080 по умолчанию недоступен с других машин: по нему открытым текстом
идут код настройки и пароль администратора. Как открыть консоль и раздачу пакетов —
[раздел 4](04-tls-and-names.md).

## Имя сервера

Агентам нужно постоянное имя сервера: DNS-имя (`sard.example.com`) или
постоянный IP. Оно попадает в сертификат сервера (`SARD_PKI_SERVER_NAMES`) и
запоминается агентами при регистрации. Смена имени потом — это перевыпуск
сертификата и правка конфигов агентов, поэтому имя лучше выбрать до первой
регистрации. В облаке — зарезервированный (reserved) IP или DNS-запись на
него.

## Хосты агентов

Linux amd64 или arm64 с systemd (пакеты deb, rpm, tar.gz); restic входит в
пакет. Плагин `files` на этапе 1 — единственный. Windows, macOS и сетевое
оборудование пока не поддерживаются.
