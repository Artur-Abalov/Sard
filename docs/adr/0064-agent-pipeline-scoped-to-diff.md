# 0064 — Конвейер агентов работает по диффу; полный аудит — по запросу

- Статус: принято (сессия `docs/sessions/2026-10-19-agent-pipeline-optimization.md`).
  Цифры экономии — только измеренные, см. таблицу в журнале сессии.
- Дата: 2026-10-19

## Контекст
`/ship-feature` и `/quick-fix` тратят токены и время на то, что не относится к
изменению: архитектор получает дерево Maven-зависимостей сервера (434 строки,
29 450 байт, измерено) вместо границ модулей; хук `SubagentStop` гоняет быстрый
шлюз после каждого субагента, включая тех, кто файлов не меняет (один запуск для
`tools` — 49,5 с, измерено); cleaner и hardener идут по всему модулю; specifier по
собственной воле открывает большой образец (в замере — `docs/qa/host-check.md`,
21 762 символа из примерно 46 КБ вывода инструментов).

## Решение
1. **Охват — дифф.** architect, cleaner и hardener работают с файлами из
   `git diff --name-only origin/main` (закоммитенные и нет) и новым файлам из `git status --short`;
   трёхточечная форма `origin/main...` не годится: во время прогона правки ещё не закоммичены.
   Полный аудит architect запускает, когда
   вызывающий пишет «перед началом большой функции» или просит его.
2. **Структурные факты — скриптом.** `scripts/claude/arch-edges.sh` печатает рёбра
   пакетов Go, запрещённые импорты в доменном коде сервера и `PASS`/`FAIL` для
   лицензионной границы и «агент не слушает порт». Правила `PASS`/`FAIL` проверяются
   по всему дереву при каждом запуске. Доменные пакеты сервера задаются списком
   `SERVER_DOMAIN` в начале скрипта (сейчас `workflow`, `role`, `metrics` — единственные
   без импортов фреймворка); остальные смешивают Spring-обвязку и логику и не проверяются.
3. **Быстрый цикл тестов.** `scripts/claude/test-quiet.sh <модуль> [фильтр]` печатает
   только провалы. Полный набор тестов — один раз перед шлюзом. Шлюз `gate.sh <модуль> fast`
   по-прежнему обязателен и прогоняет все тесты.
4. **Хук.** Не запускать шлюз после `specifier` и `architect` (по непустому
   `agent_type`); не повторять шлюз на дереве, уже прошедшем те же модули
   (`build/.gate-ok/`). Провал не кэшируется. Изменение файлов, защищённых
   `guard-edit.sh`, поставляется патчами в `docs/proposals/agent-optimization/`.
5. **Индексы.** `scripts/claude/docs-index.sh` порождает `docs/specs/INDEX.md` и
   `docs/sessions/INDEX.md` (журнал сессий только дописывается, правило 8).
6. **Стоимость видна.** Строка статуса стадии и итоговая таблица содержат
   `subagent_tokens`, `tool_uses`, `duration_ms` из уведомления о завершении агента.
7. `git fetch origin main` при старте сессии: устаревший локальный `origin/main`
   заставлял `gate-changed.sh` считать изменёнными все 8 модулей.

## Что на обычном прогоне больше не проверяется
- architect не читает файлы вне диффа на швы, направление зависимостей и размер.
  Правила лицензионной границы и «без слушателя» проверяются по всему дереву.
  Полный аудит — по запросу (п. 1).
- cleaner не трогает функции вне диффа с CRAP выше порога; они попадают в отчёт
  одной строкой.
- hardener сначала мутирует пакеты/классы диффа; полный шлюз модуля по-прежнему
  запускается один раз в конце и определяет итоговый результат.
- coder запускает полный набор тестов модуля один раз перед шлюзом, а не после
  каждого шага: регрессия вне нового теста выявляется позже, но не позднее шлюза.
- Хук пропускает повторный шлюз на неизменном прошедшем дереве. Не покрыто:
  состояние вне хеша дерева (Docker, сеть, зависимости) и повторный прогон
  нестабильного теста; `GATE_NO_CACHE=1` отключает кэш.
- specifier не читает исходный код и журналы сессий (исключение — пользовательское
  имя, флаг или сообщение из запроса).

## Не меняется
Пороги, шаги и порядок шлюзов, вердикты (`STRUCTURE ACCEPTED` / `CHANGES REQUIRED`),
таблица CRAP до/после, счётчики выживших мутантов, границы ролей, модели агентов.

## Отвергнуто
- «`crap.sh <модуль> 10`»: вывод и так 31 строка (1,6–2,1 КБ, измерено), выигрыша нет.
  Сохранён только охват по диффу.
- Отдельный пункт «не читать сгенерированные файлы» как экономия: ни одна инструкция
  их читать не велела, в замерах чтений не было. Одна строка в `coder.md` без
  заявленной экономии.
- Правка защищённых файлов в обход охраны.
