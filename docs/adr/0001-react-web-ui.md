# 0001 — React для веб-интерфейса

- Статус: принято; роутер заменён на TanStack Router (ADR 0015)
- Дата: 2026-09-26

## Контекст
Нужна SPA-консоль: дашборд, формы конфигурации плагинов по JSON Schema, таблицы агентов и запусков. Команда небольшая; важны экосистема компонентов, типизация и найм.

## Решение
React 19 + TypeScript + Vite (шаблон `react-ts`), React Router, TanStack Query для серверного состояния, react-i18next (ru, en).

## Причины
- Крупнейшая экосистема: готовые UI-киты (ADR 0003), генераторы форм по JSON Schema, генерация типизированного клиента из OpenAPI (`openapi-typescript` + `openapi-fetch`).
- TanStack Query снимает ручное кеширование и повторные запросы.
- Vite — быстрый dev-сервер с прокси на сервер и простая сборка статики.

## Отвергнуто
- Vue, Svelte — меньше выбор зрелых компонентов для административных консолей.
- Серверный рендеринг (Next.js и т. п.) — не нужен внутренней консоли; раздача статики из jar сервера вне рамок каркаса.
- Kotlin/JS или Compose for Web — единый язык с сервером, но незрелая экосистема UI.
