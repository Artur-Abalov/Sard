# 0007 — Шлюзы качества и инструменты

- Статус: принято
- Дата: 2026-09-26

## Решение
Шлюз — `scripts/gate.sh <module> [fast]`, пороги заданы только там:

| Метрика | Порог | Go | Kotlin | Веб |
|---|---|---|---|---|
| тесты | зелёные | `go test` | JUnit через Gradle | Vitest (чистые функции) |
| покрытие | ≥ 80% | `go test -coverprofile` | JaCoCo | не меряется |
| CRAP на функцию | ≤ 6 | `.bin/crap` | `.bin/crap` по JaCoCo XML | — |
| цикломатика | ≤ 8 | golangci-lint `gocyclo` | detekt | ESLint `complexity` |
| мутации | ≥ 0.80 | go-mutesting | ADR 0006 | — |

- Инструменты Go закреплены в отдельном модуле `tools/` (директива `tool`), вне `go.work`, собираются `make tools` в `.bin/`. Так их тяжёлый граф зависимостей не влияет на продуктовые модули.
- `crap` — собственная утилита на stdlib (`tools/cmd/crap`): цикломатика по AST в стиле gocyclo + покрытие операторов из профиля Go; для JVM — счётчики COMPLEXITY/INSTRUCTION JaCoCo.
- JaCoCo вместо Kover: встроен в Gradle и даёт COMPLEXITY, нужный для CRAP.
- Сгенерированный код (`proto/gen/go`, protobuf-классы сервера) из метрик исключён.

## Причины
Пороги повторяют проверенные в предыдущем проекте владельца; CRAP ≤ 6 при полном покрытии фактически ограничивает цикломатику 6.

## Отвергнуто
- gremlins — последний релиз в мае 2024; выбран `avito-tech/go-mutesting` (MIT, активен, но без релизных тегов — закреплён псевдоверсией).
- pitest — отвергнут владельцем по опыту (мусорные мутанты на байткоде Kotlin).
