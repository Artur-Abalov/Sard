# 0017 — restic поставляется вместе с агентом

- Статус: принято
- Дата: 2026-09-27

## Контекст
Агент хранит данные через restic (ADR 0008). От версии restic зависят формат
`--json`, коды выхода и поведение при отмене; restic из дистрибутива бывает
на годы старше (Debian 12 — 0.14). Решение владельца D3: restic
поставляется вместе с агентом.

## Решение
- Одна закреплённая версия, которую прогоняют тесты: **0.19.1**. Минимальная
  принимаемая — **0.19.0**: с неё отмена даёт код 130, а отсутствующий путь
  копии — 3 (CHANGELOG 0.19.0); коды 10/11/12 — с 0.17.
- Единственный источник — `agent/internal/restic/restic-version`: версия,
  минимальная версия, SHA-256 архивов linux/amd64 и linux/arm64, отпечаток
  ключа подписи релизов. Его читают `scripts/fetch-restic.sh`, пакет
  `restic` (`//go:embed`) и интеграционные тесты.
- `scripts/fetch-restic.sh` скачивает официальный релиз с GitHub в
  `.bin/restic/<версия>/linux_<arch>/` и принимает архив, только если его
  SHA-256 совпадает и с закреплённым в репозитории, и со строкой в
  `SHA256SUMS` релиза. Подпись `SHA256SUMS.asc` проверяется, если есть gpg
  и ключ (`RESTIC_SIGNING_KEY`); `REQUIRE_SIGNATURE=1` делает её обязательной.
- Путь к restic — `restic.path` в конфиге агента; по умолчанию `restic`
  рядом с бинарником `sard-agent`. Кэш — `restic.cache_dir`, по умолчанию
  `/var/cache/sard/restic`.
- При запуске версия проверяется функцией `CLI.Version()` (ошибка
  `ErrUnsupportedVersion`); сообщение оператору — задача A5b.
- restic лицензирован BSD-2: текст лицензии лежит в
  `third_party/restic/LICENSE` и кладётся рядом с бинарником
  (`LICENSE.restic`); упаковка — ADR 0018.
- Гейт `agent` скачивает закреплённый restic и прогоняет
  `go test -tags integration ./internal/restic/...`.

## Оборотная сторона
- Обновление restic — это релиз агента: новая версия, суммы и golden-вывод
  в `agent/internal/restic/testdata` меняются одним PR.
- Гейт и CI зависят от доступности github.com.
- Оператор может указать свой restic через `restic.path`; ниже 0.19.0 агент
  его не примет, выше — не протестирован.

## Отвергнуто
- restic из PATH или пакетного менеджера хоста — версия непредсказуема.
- Встраивание restic как Go-библиотеки — у restic нет стабильного API, и
  агент потерял бы отделение процесса (отмена, память, падения).
- Доверять только `SHA256SUMS` релиза — защищает лишь от битой загрузки.

## Отложено
- Ключ подписи релизов restic в репозитории и `REQUIRE_SIGNATURE=1` в CI:
  ключ не удалось получить из окружения разработки (keys.openpgp.org и
  restic.net закрыты политикой сети).
