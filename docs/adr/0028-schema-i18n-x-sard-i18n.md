# 0028 — Переводы `config_schema` плагинов: ключ `x-sard-i18n`

- Статус: принято
- Дата: 2026-09-30

## Контекст
Консоль (W2) строит форму настройки источника из `config_schema` плагина
(ADR 0027). Стандартные `title` и `description` JSON Schema — на одном языке,
а консоль двуязычная (`web/src/locales/{ru,en}.json`). Плагин files (A6b)
первым получает заголовки, описания и примеры у каждого поля, и владелец
(OQ-042, решение Ф3, 2026-09-30) решил, где хранить перевод.

Варианты:
- переводы в `web/src/locales`: каждый плагин, в том числе сторонний,
  требует правки веба; форма зависит от знания вебом полей плагина;
- отдельный ресурс плагина рядом со схемой: второй артефакт, который надо
  регистрировать и сверять по версиям со схемой;
- переводы внутри схемы, в расширяющем ключе.

## Решение
Перевод лежит в схеме, в ключе `x-sard-i18n` того же объекта, что и
переводимые `title` и `description`:

```json
"paths": {
  "type": "array",
  "title": "Paths",
  "description": "Absolute paths of the directories and files to back up.",
  "x-sard-i18n": {
    "ru": {"title": "Пути", "description": "Абсолютные пути каталогов и файлов."}
  }
}
```

- `title` и `description` стандартных ключей — английские: это язык по
  умолчанию и откат.
- `x-sard-i18n` — объект «код языка → `{title, description}`»; код языка —
  двухбуквенный (`ru`), оба поля необязательны.
- Консоль берёт перевод языка интерфейса; нет языка или нет поля в переводе —
  английский текст из стандартного ключа. Ключ работает на любом уровне
  схемы, где допустимы `title` и `description`.
- Агент и сервер ключ не интерпретируют: JSON Schema разрешает неизвестные
  ключевые слова (валидатор их игнорирует), а Register S4a хранит схему как
  есть. Действуют те же ограничения на схему: один JSON, не больше 64 КиБ,
  без `\u0000`.
- Сторонний плагин переводит свою схему сам, без изменений в `web/`.

## Последствия
- Схема растёт: у files переводы занимают порядка килобайта из 64 КиБ.
- Проверка переводов — в тестах плагина (files: у каждого поля есть `ru`
  с непустыми `title` и `description`), не в агенте: агент не отвергает
  схему без переводов.
- Чтение ключа и откат на английский — задача W2; её сценарии пишет
  specifier для W2.
