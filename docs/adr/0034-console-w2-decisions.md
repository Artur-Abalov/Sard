# 0034 — Консоль W2: признак `partial`, обзор по запросу, адресная строка

- Статус: принято (спецификации W2 утверждены владельцем 2026-10-02, OQ-072…OQ-084)
- Дата: 2026-10-02

## Контекст

Страницы консоли этапа 1 (W2) потребовали трёх серверных полей (К14–К16) и
нескольких решений на стороне веба, которые нельзя вывести из спецификации.

## Решение

- **`BackupOutput.partial` хранится в `run_steps.output`** (поле `partial` в JSON
  вывода бэкапа), а не вычисляется при чтении. `ResultCheck` ставит его в момент
  записи результата: `true`, если статус результата не `succeeded`. Так признак
  равен `snapshots.partial` того же результата и верен для позднего вывода
  потерянного шага (его результат `succeeded` → `false`, шаг остаётся `lost`).
  Строки, записанные до К16, читаются как `partial = false`; миграции не нужно.
- **Обзор считается при каждом запросе** (`fleet.Overviews`), ничего не хранит:
  пять запросов `count` по тенанту сессии и список неотозванных агентов. Онлайн —
  по менеджеру стримов, как в `GET /agents`. «Первые шаги» определены правилами в
  `docs/specs/server/rest-api-w2.feature`; `complete` — конъюнкция пяти.
- **`sourceName` и `sourceDeleted` — из строки источника** (мягкое удаление
  оставляет имя): список запусков присоединяет `sources`, карточка читает источник
  по `source_id`.
- **Адресная строка веба без JSON.** Роутер получает `parseSearch` и
  `stringifySearch` на `URLSearchParams` (`web/src/searchParams.ts`): параметр,
  данный несколько раз, — список. Иначе `?status=failed&status=running` роутер
  переписывал бы в JSON-вид при каждом открытии, а спецификация требует именно
  повторяющиеся параметры. Значения не разбираются как JSON: `?redirect=42` — строка.
- **Опрос — на TanStack Query** (`refetchInterval` от чистых функций
  `web/src/polling.ts`); приостановка во скрытой вкладке и запрос при возврате —
  поведение по умолчанию (`refetchIntervalInBackground: false`, `refetchOnWindowFocus`).
  Логи шага читает хук `useStepLog` (страницы по `nextAfterSeq`, хвост по таймеру,
  дочитывание после завершения) через `queryClient.fetchQuery`, чтобы 401 шёл тем же
  путём, что и у остальных запросов.
- **401 при записи.** `MutationCache` клиента запросов реагирует на
  `UnauthenticatedError` так же, как `QueryCache`.
- **Новых зависимостей нет.**

## Отклонено

- Вычислять `partial` при чтении из `snapshots` по `step_id`: при конфликте
  `on conflict do nothing` (тот же снимок у другого шага) строки нет, признак
  терялся бы.
- Хранить «первые шаги» отметками в БД: они устарели бы после удаления источника
  или отзыва агента, а спецификация требует, чтобы они снимались.
- Пользоваться JSON-разбором адресной строки TanStack Router: см. выше.
