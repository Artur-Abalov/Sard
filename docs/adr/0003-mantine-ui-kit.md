# 0003 — Mantine как UI-кит

- Статус: принято
- Дата: 2026-09-26

## Решение
`@mantine/core` + `@mantine/hooks` (Mantine 9), настройка PostCSS по официальной инструкции для Vite (`postcss-preset-mantine`, `postcss-simple-vars` с брейкпоинтами), тема — один файл `web/src/theme.ts`, светлая, тёмная и системная схемы через `defaultColorScheme` и `useMantineColorScheme`.

## Причины
- Готовые компоненты административного UI (AppShell, таблицы, формы, уведомления) без собственной дизайн-системы.
- Встроенные светлая/тёмная схемы без дополнительных библиотек.
- CSS-модули и CSS-переменные, без CSS-in-JS в рантайме.
- MIT-лицензия.

## Отвергнуто
- MUI — тяжелее, Emotion в рантайме.
- Ant Design — сильная собственная стилистика, сложнее тематизация.
- Tailwind + headless-компоненты — больше собственного кода компонентов на старте.

## Проверено
`npm run dev` при запущенном сервере: дашборд на компонентах Mantine, «Последнее проверенное восстановление: —», переключение ru/en и светлой/тёмной темы (Chromium через Playwright, скриншоты в сессии).
