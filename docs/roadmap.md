# План развития Sard

[English](roadmap.en.md)

> **Это план, а не обещание.** Здесь перечислено то, чего в Sard ещё нет. Сроков нет;
> порядок может измениться. Что работает сейчас — в [README](../README.md) и
> [docs/plugins/](plugins/).

## Работает сейчас

Источники: файлы и каталоги ([files](plugins/files.md)) и PostgreSQL
([postgresql](plugins/postgresql.md)). Хранилища restic: локальный диск, S3, SFTP.

## Ближайшее: замкнуть цикл

Бэкап → восстановление из консоли → автоматическая проверка восстановления → хранение
по сроку и проверка репозитория — для файлов и PostgreSQL. Пока цикл не замкнут, новых
источников не добавляем.

## Источники потом

Выбирают первые пользователи; в списке — кандидаты, не обязательства:

- 1С на PostgreSQL;
- конфигурации сетевых устройств MikroTik и Eltex;
- MySQL.

Источник появляется в Sard вместе с работающим плагином и его страницей в
`docs/plugins/` (ADR 0056).
